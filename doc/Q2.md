# 任务指令：集成 MiniVision 静默活体 TFLite 模型 (Android)

## 1. 任务背景与系统环境

* **目标**：在现有基于 CameraX 和 ML Kit 的人脸识别链路中，插入基于深度学习的 2D 纯静默活体检测模块，防御静态照片与屏幕回放攻击。
* **宿主设备**：低端设备 MediaTek MT6762，2GB RAM，Android 10。


* **现有链路限制**：CameraX 采用约 800ms 节流策略进行检测。检测到人脸后触发 SimFace 特征提取（耗时约 230ms）。


* **资源库依赖**：复用项目现有的 `LiteRT/TensorFlow Lite` 库，**绝对禁止**引入 `ncnn` 或任何 C++/JNI 层编译配置。



## 2. 模型规范说明

模型文件为 `assets/model_float32.tflite`。
* **本地地址** D:\workspace\jq-apk-ui\Biometrics-SimFace-main\mini-fasnet-tflite-models\MiniFASNetV2_float32.tflite

* **输入 Tensor**：`[1, 80, 80, 3]` (NHWC，数据类型 Float32)。
* **输出 Tensor**：`[1, 3]` (数据类型 Float32，输出为未激活的 Logits)。
* **类别映射**：`Index 0` = Fake 2D (假)，**`Index 1` = Real (真活体)**，`Index 2` = Fake 3D (假)。

## 3. 核心实现要求：`MiniVisionLivenessDetector` 类

请创建一个专用的分类器类 `MiniVisionLivenessDetector`。此类需包含初始化、推理和资源释放方法。

### 3.1 TFLite Interpreter 初始化

* 在构造函数中加载 `.tflite`，配置 `Interpreter.Options`。
* 由于设备为 MT6762 的 Cortex-A53，请**设置 CPU 线程数为 2 到 4**（`setNumThreads(2)`）。不需要开启 NNAPI 或 GPU 代理。



### 3.2 数据预处理（极其核心，必须严格遵守）

创建一个推理方法 `public boolean isLive(Bitmap frameBitmap, Rect mlKitBoundingBox)`。在执行推理前，**必须执行以下 4 步预处理：**

1. **2.7倍中心框膨胀 (Scale Expansion)**：
* 获取 `mlKitBoundingBox` 的中心点 `centerX` 和 `centerY`。
* 计算新的宽高：`newWidth = originWidth * 2.7f`，`newHeight = originHeight * 2.7f`。
* 计算出新的裁剪框 `Rect`，并**务必执行边界安全约束（clamp）**，防止左上角小于 0 或右下角超出 `frameBitmap` 的真实宽高。


2. **Bitmap 裁剪与缩放**：
* 基于上一步的安全框，从 `frameBitmap` 中裁剪出人脸上下文区域。
* 将该裁剪区域强行 `resize` 为 **80 x 80** 的 Bitmap。


3. **色彩空间转换 (RGB 转 BGR) 与 归一化**：
* 模型基于 OpenCV 训练，要求输入通道顺序为 **BGR**（非 Android 默认的 ARGB/RGB）。
* 初始化 `ByteBuffer`：容量为 `1 * 80 * 80 * 3 * 4` 字节，`ByteOrder.nativeOrder()`。
* 使用 `bitmap.getPixels()` 提取整数数组。遍历每个像素，**除以 255.0f**。
* **压入顺序必须为 B、G、R**：
```java
int p = pixels[i];
float r = ((p >> 16) & 0xFF) / 255.0f;
float g = ((p >> 8) & 0xFF) / 255.0f;
float b = (p & 0xFF) / 255.0f;
byteBuffer.putFloat(b);
byteBuffer.putFloat(g);
byteBuffer.putFloat(r);

```





### 3.3 后处理与 Softmax 计算

* 模型输出为一个 `float[][] output = new float[1][3];`
* **因为模型输出的是 Logits，你必须手动实现 Softmax 以换算概率**：
```java
float[] logits = output[0];
float maxLogit = Math.max(logits[0], Math.max(logits[1], logits[2]));
float sumExp = 0;
for (int i = 0; i < 3; i++) {
    sumExp += Math.exp(logits[i] - maxLogit); // 减去最大值防溢出
}
float realProbability = (float) (Math.exp(logits[1] - maxLogit) / sumExp);

```


* **拦截阈值**：如果 `realProbability > 0.90f`，返回 `true`（活体通过）；否则返回 `false`（拦截）。

## 4. 业务管线集成约束 (接入层)

请修改当前 CameraX `ImageAnalysis` 的检测回调逻辑：

1. 在拿到 ML Kit `Face` 对象后，如果姿态角 (Yaw/Roll) 合格，优先调用 `MiniVisionLivenessDetector.isLive()`。


2. **只有 `isLive()` 返回 `true` 时**，才向后放行，调用 SimFace 的 `alignedFaceImage` 和 `getEmbedding` 流程。


3. **异常与拦截处理**：如果判断为照片（返回 `false`），务必更新 UI 提示“未检测到活体”，并**立即调用 `ImageProxy.close()` 释放帧缓冲**，直接 `return` 等待下一个 800ms 周期。


4. 所有上述计算必须在现有的分析线程 (`Executor`) 中串行执行，禁止新开线程池导致 2GB 内存 设备发生上下文切换 OOM。
